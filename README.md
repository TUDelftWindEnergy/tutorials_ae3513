# Tutorials AE3513

Interactive Python tutorials for the course AE3513 at Delft University of Technology, built with [Jupyter Book 2 / MyST](https://mystmd.org).

## Content
- `content/`: the tutorial notebooks (FLORIS, PyWake, airborne wind energy, storage)
- `myst.yml`, `toc.yml`, `authors.yml`: book configuration
- `binder/`: environment used for the interactive Binder sessions
- `pixi.toml`: local development environment

## Local development
```
pixi install
pixi run preview   # live preview at http://localhost:3000
pixi run editor    # JupyterLab
```
